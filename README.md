# QazaqPeek Cyber Club — Semantic HTML5 Website

## Project Overview
This repository contains Assignment 1 for Introduction to Web Technologies. The project models a six-page website for **QazaqPeek Cyber Club**, a real physical esports lounge located at Kenesary Street 69 in Astana, Kazakhstan.

In strict compliance with assignment guidelines, this project utilizes **only semantic HTML5 markup**. No external, internal, or inline Cascading Style Sheets (CSS) or JavaScript scripts are included.

## Student Information
* **Students:** Dias Tursynbay and Ainadinov Adilet
* **Mode:** Collaborative Project (6 pages)

## Site Architecture & Files
* `index.html`: Venue background, atmosphere overview, physical hardware gallery, and operating schedule.
* `services.html`: Zone tariff matrix, station hardware peripherals, balance top-up guide, and esports terminology glossary.
* `booking.html`: Station reservation form with native HTML5 validation and contact channels.
* `events.html`: Community event calendar, tournament information, and participation steps.
* `login.html`: Static login and registration forms for club members. The forms do not connect to a server.
* `colophon.html`: Technical retrospective detailing tools, file layout, and terminal validation logs.
* `checklist.txt`: Line-by-line inventory of all required HTML5 tags and elements.
* `ai_log.md`: Log of AI interactions in compliance with course policy.
* `images/`: Local photographic evidence taken on-site at Kenesary 69.

## Compliance & Validation
* **W3C Nu HTML Checker:** All 6 pages validated with 0 errors and 0 warnings.
* **Heading Hierarchy:** Strictly enforced single `<h1>` per page with sequential `<h2>` and `<h3>` tags.
* **Accessibility:** All form controls bound via `for`/`id` labels; all tabular data structured via scoped `<th>` headers.
