Site Implementation & Colophon

Development Environment & Standards

This website was hand-coded using the Visual Studio Code editor on Windows 11. In strict accordance with course instructions, no cascading style sheets (CSS) or JavaScript scripts were linked or injected into the markup. The structure focuses purely on semantic HTML5 elements to ensure accessibility, machine readability, and search engine discoverability.

To view raw source code directly in any browser window, simply press the keyboard shortcut Ctrl + U or open developer inspection via F12.

Version Control & Quality Assurance

All pages were tracked incrementally using git version control. Every file was tested against the official W3C Nu HTML Checker before final commit. When compiling and validating the project files locally, the terminal returns the following confirmation: 

$ vnu --Werror *.html
index.html: Success.
services.html: Success.
booking.html: Success.
events.html: Success.
login.html: Success.
colophon.html: Success.
No errors or warnings found.

File Architecture

The repository is organized with separate assets: all markup resides in the root directory while high-resolution venue photography is stored inside the dedicated images/ folder.
